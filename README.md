# Proofy — проверенные достижения школьников

Gambit Hackathon 2026 · трек HackHub · кейс «Талант до вуза»

**Одной фразой:** организатор конкурса выдаёт сертификат с QR-кодом, а вуз или образовательное агентство за 5 секунд проверяет, что он настоящий и чего стоит сам конкурс.

## Выбранный разрыв

**Доверие.** Грамоты легко подделать или купить, а платный онлайн-конкурс выглядит так же, как областная олимпиада.

## Пользователь и платящий клиент

- **Школьник:** 9–11 класс, Актобе и малые города области, IT и олимпиады. Ему нужно показывать достижения одной ссылкой при подаче на гранты, стажировки и поступление.
- **Платящий клиент:** образовательные агентства, которые готовят к поступлению за рубеж, и приёмные комиссии вузов. Платят за проверку сертификатов и доступ к поиску проверенных школьников.
- **Источник доверия:** организаторы конкурсов. Выдача сертификатов для них бесплатная.

## Как работает механизм

1. Сертификат создаёт только организатор: загружает список призёров, каждый получает ID (`PRF-GH26-0001`) и QR.
2. При проверке сервис ищет ID в реестре, сверяет результат из документа с реестром и пересчитывает SHA-256 отпечаток записи.
3. **Вес конкурса (0–100):** уровень (20–85) + число участников (до +15) + отбор (+10) − неподтверждённый организатор (−30) − платное участие без отбора (−25) − награждено больше 50% (−20).
4. **Баллы за достижение** = вес × коэффициент результата (победитель 1,0 · призёр 0,7 · финалист 0,4 · участник 0,15).

## Данные несовершеннолетних

- Профиль скрыт по умолчанию; в поиск попадает только с согласия родителя и анонимно.
- Имя и контакт покупатель видит только после того, как школьник одобрил его запрос.
- Не собираем ИИН, телефон и фото. **В прототипе все данные тестовые.**

## Демо-сценарий (2 минуты)

1. **Главная** → интро 5 секунд, затем блок «Сколько весит грамота?»: кнопки «Областная олимпиада» и «Платная «международная»».
2. **Проверка** → «Настоящий», «Подделка», «Изменён результат», «Платный конкурс». Кнопка «Сканировать QR» читает QR камерой (или «Демо-скан»).
3. **Организаторам** → Gambit Hackathon 2026 → «Вставить пример» → «Выдать сертификаты».
4. **Школьникам** → «Открыть контакт» у запроса агентства, переключатели согласия, превью «Так вас видит вуз».
5. **Вузам и агентствам** → фильтры по городу и весу → «Запросить контакт».
6. **API** → журнал всех запросов, сделанных за сессию.

Кнопка «?» в шапке запускает мини-инструкцию для текущей страницы. Внизу есть «Показать интро» и «Сбросить демо-данные». Ссылка с `?nointro` открывает сайт без интро.

## Архитектура прототипа

Фронтенд работает через слой API (`API.verify`, `API.issue`, `API.consent`, `API.request` в `app.js`) с REST-путями `/v1/...`, кодами ответа и журналом. **В прототипе этот слой выполняется в браузере** с имитацией сетевой задержки, а данные лежат в `localStorage`. В рабочей версии те же вызовы уходят на сервер, а каждую запись реестра подписывает ключ организатора (ECDSA).

## Как запустить

Сборка не нужна, это статический сайт.

- **Онлайн:** https://nuralyga07-netizen.github.io/proofy/
- **Локально:** `python -m http.server 5173` в этой папке, затем открыть http://localhost:5173
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.

Данные хранятся в `localStorage` браузера.
